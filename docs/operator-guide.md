# Operator Guide

## First Deployment
1. Register the bureau/wire desk, its editorial staff and subscriber
   media outlets.
2. Import existing story, sourcing and distribution history.
3. Run read-only sourcing and embargo dry-runs.
4. Configure the rollout phase (0-3) and human sign-off paths.
5. Publish a dry-run distribution record and audit export.

## Minimum Production Controls
- sourcing-checklist validation before any distribution
- governor gate on every distribution/correction before commit
- human sign-off for legally-sensitive stories and for every
  correction/retraction, regardless of phase or confidence
- an independently recomputed embargo-instant check, not a proposal-
  reported one
- audit export for every intake, verification, screening,
  distribution and correction/retraction record

## Certification
Certified operators must prove sourcing discipline, embargo
compliance, legal-sensitivity review coverage, and human review for
every correction/retraction.
